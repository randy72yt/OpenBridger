## 一、协议适用范围

本协议适用于通过 OpenBridger 提供的网站、控制台、AI API 网关、模型接口转发、API Key 管理、用量查询、额度及相关技术服务。具体开放功能以平台实际提供的服务为准。

OpenBridger 面向学习实践、课程项目、软件开发和团队应用集成等场景。若您代表组织使用服务，应具有相应授权，并明确组织内部的账号、凭证与数据使用权限。

本平台仅面向非中国大陆地区用户。请您自行确认访问及使用本服务符合所在地适用法律法规、上游服务条款及平台规则；因违反相关规定产生的责任，依法由相应责任主体承担。公开页面不陈述运营所在地。

**待确认：**协议接受方式与最低使用年龄。上线时应在相应流程中清晰展示适用版本及接受方式，不能仅依靠本页文字代替实际告知。

## 二、服务内容与第三方模型

平台通过统一接口转发请求至相应模型服务商，并提供账号、凭证、额度和调用记录管理。不同模型支持的接口、参数、能力和可用性可能不同，实际接入请以平台公布的模型信息及实用教程为准。

第三方模型可能因维护、上游策略、速率限制或网络问题而暂时不可用。模型输出可能存在错误、遗漏、偏差或过时信息，用户应结合具体用途进行核验。

学习与课程场景应遵守所在学校、课程或研究项目的学术诚信和 AI 使用要求；发布代码、报告或其他成果前，应核查准确性及相关权利。

## 三、账号与 API Key 安全

用户应提供准确的必要账号信息，并妥善保管密码、API Key、访问令牌及其他认证凭证。请勿将可用凭证公开在代码仓库、前端页面、截图或公共日志中。

团队应按职责管理访问权限，及时撤销不再使用的凭证。发现泄露或异常调用时，应尽快禁用相关 Key、更新凭证，并通过平台公布的安全联系方式反馈。

账号异常和相关责任应结合实际授权、各方过错及适用法律处理，不将所有账号活动一概认定为用户本人操作。

## 四、用户内容与使用边界

用户应确保其有权提交和处理提示词、文件、图像、音频及其他内容，并在涉及他人个人信息或保密材料时取得必要授权。

用户依法享有的内容权利不因使用平台而当然转移。平台处理用户内容的范围应限于提供服务所必需的请求转发、任务处理及经说明的其他目的，具体以经确认的隐私政策为准。

不得利用服务实施违法活动、侵权、诈骗、恶意攻击、未经授权的数据获取，或绕过计费、限流和安全控制。

**待确认：**账号共享、商业转售、研究评测和模型训练的具体边界。参考站禁止竞争模型训练与基准测试的条款不直接移植，以免与学生研究和开发者使用场景冲突。

## 五、价格、额度与支付

如平台开放收费服务，应在购买前展示价格、计量方式、模型倍率、额度有效期、套餐权益、购买限制和适用费用。订单权益应有可查询的记录，价格或规则变更应清晰告知。

**待确认：**钱包额度性质与有效期、套餐期限、自动续费是否开放、支付服务商、支付信息处理方式、币种、税费和账单描述符。未经确认，本稿不声明已接入任何支付渠道或已提供特定付款功能。
