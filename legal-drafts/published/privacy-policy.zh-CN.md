# OpenBridger 隐私政策

**版本：** 1.0
**生效日期：** 2026 年 9 月 26 日
**运营主体：** OpenBridger
**联系方式：** support@openbridger.com

## 一、适用范围

本政策说明 OpenBridger 在提供网站、控制台、API 转发、凭证管理、用量查询及相关服务时，对个人信息的处理方式。

第三方模型服务商及其他独立服务可能按照各自政策处理信息。平台在实际接入时说明相关服务商、处理目的及必要的数据流向。

本平台仅面向非中国大陆地区用户开放。请您自行确认访问及使用本服务符合所在地适用法律、上游服务商条款及平台规则；因违反相关规定产生的责任，由相应责任主体承担。

## 二、我们收集的信息

| 数据类别 | 涉及的信息 | 主要用途 |
| --- | --- | --- |
| 账号资料 | 用户名、邮箱、昵称、账号状态及权限信息 | 创建和管理账号 |
| 认证与安全信息 | 密码哈希、已启用的 OAuth 绑定信息、二次验证或 Passkey 状态、登录记录 | 身份验证和账号保护 |
| 网络与访问记录 | IP、User-Agent、请求时间、响应状态及必要设备信息 | 服务交付、故障排查和安全防护 |
| API 调用元数据 | 模型、请求标识、用量、消耗、耗时、状态及必要错误信息 | 请求处理、计费、统计和排障 |
| 请求与任务内容 | 提示词、上下文、文件及模型输出 | 完成您发起的调用或任务 |
| 主动提交的支持信息 | 您提供的问题说明、反馈及经过必要脱敏的材料 | 客户支持 |

我们不会要求您提交与服务无关的敏感信息。提交支持材料时，请避免包含可用的 API Key、密码或无关的个人信息。

## 三、信息使用目的

我们基于为您提供服务、保障安全及履行法律义务处理上述信息，具体包括：

- 创建、验证和维护账号，保存必要偏好；
- 转发模型请求、返回响应和处理异步任务；
- 计算调用用量、展示使用记录；
- 排查故障，防止账号盗用、攻击与滥用；
- 处理您的反馈、权利请求及必要的服务通知；
- 履行适用法律规定的义务。

我们不会将您的个人信息作为商品出售。

## 四、API 请求内容与日志

完成模型调用通常需要将您的请求内容传输给您所选的上游服务商。我们区分请求转发所需的临时处理、调用元数据记录与完整内容的持久化存储，并在实际启用相关能力时作出说明。在核实并明确说明之前，我们不作出「零日志」或「不保存请求内容」的承诺。

请您避免提交无关的个人信息、生产环境密钥或未经授权的保密材料；使用学校或团队数据时，应遵守相应的授权要求。

## 五、Cookie 与本地存储

登录会话、语言和主题偏好可能使用 Cookie 或浏览器本地存储。您可以通过浏览器管理这些数据；删除必要数据可能导致退出登录或偏好重置。

如平台启用分析类工具，将在启用时说明用途、期限及可用的选择与撤回方式。

## 六、共享与委托处理

我们仅在提供服务所必需的范围内，向实际使用的服务商提供必要信息，例如：上游模型服务商、服务器与基础设施提供方、邮件发送服务、身份认证服务。

上述服务商按其自身政策处理信息，并在其职责范围内承担相应责任。我们不会超出服务所需范围共享您的个人信息。

## 七、支付信息

本平台当前未开放在线支付功能，不收集银行卡号等支付凭证信息。如后续开放付费功能，本政策将在功能开放前更新，说明平台与支付处理方分别处理的信息范围。

## 八、跨境处理

模型服务、服务器托管及其他供应商可能位于您所在地区以外。我们在实际接入时说明接收地区、接收方及处理目的，并按适用要求落实必要手续与保障措施。

## 九、保存与删除

信息保存期限与处理目的、账务、安全及适用法律要求相匹配。无需继续保留的信息将按实际可执行流程删除或匿名化。

| 数据类别 | 保留期限和到期处理 |
| --- | --- |
| 账号及认证资料 | 账号存续期间保留；注销后按适用法律与争议处理需要保留必要期间后删除 |
| API 元数据、错误与安全日志 | 按排障与安全需要保留，定期清理 |
| 完整请求、响应与任务文件 | 仅在实现功能所必需的范围内保留；如启用持久化存储，将列明期限 |
| 客服材料 | 处理完毕后保留必要期间用于后续跟进 |
| 备份副本 | 随备份周期轮换；删除请求在备份更新时同步生效 |

## 十、安全保护与事件处理

我们采用与风险相称的安全措施，包括全站 HTTPS 传输加密、密码哈希存储、权限隔离、日志脱敏、备份与访问审计。

如发生可能影响您权益的安全事件，我们将按适用要求确定通知对象、条件与时限，并采取必要的处置措施。

您也应妥善保护账号与凭证；发现异常时请及时撤销相关 Key 并通过本政策列明的联系方式告知我们。

## 十一、您的权利

在适用法律范围内，您可以请求了解信息处理情况，访问、更正、删除或获取相关数据，并对基于同意的非必要处理撤回授权。

我们受理请求时会进行与风险相称的身份核验，避免泄露他人信息。依法必须保留的数据及备份处理限制，将在必要时向您说明。

**申请方式：** 发送邮件至 support@openbridger.com，并说明您要行使的权利及必要身份信息。

## 十二、服务通知

我们区分必要服务通知（如账号安全、服务变更）与可选信息。若后续启用非必要的邮件或推广信息，将说明授权与退订方式。

## 十三、未成年人

OpenBridger 的目标用户包含学生。如您尚未达到所在地规定的成年年龄，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本服务。

## 十四、政策更新与联系方式

我们可能因服务调整或法律要求更新本政策。更新后将调整版本号并公布生效日期，重大变更将通过适当方式告知。涉及需单独授权的数据用途，不会以单纯继续访问代替必要授权。
