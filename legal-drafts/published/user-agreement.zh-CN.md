## 一、协议的适用范围

本协议适用于您通过 OpenBridger 提供的网站、控制台、AI API 网关、模型接口转发、API Key 管理、用量查询、额度及相关技术服务。具体开放的功能以平台实际提供的为准。

您注册账号、获取 API Key 或实际使用本服务，即表示您已阅读并同意本协议及配套的 [隐私政策](./privacy-policy.zh-CN.md)。若您代表组织使用本服务，您应已获得相应授权，并负责组织内部账号、凭证与数据的使用管理。

OpenBridger 面向学习实践、课程项目、软件开发和团队应用集成等场景。本平台仅面向非中国大陆地区用户开放。请您自行确认访问及使用本服务符合所在地适用法律、上游服务商条款及平台规则；因违反相关规定产生的责任，由相应责任主体承担。

如您尚未达到所在地规定的成年年龄，请在监护人陪同下阅读本协议，并在取得监护人同意后使用本服务。

## 二、服务内容与第三方模型

平台通过统一接口将您的请求转发至相应的模型服务商，并提供账号、凭证、额度和调用记录管理。不同模型支持的接口、参数、能力和可用性可能不同，实际接入情况以平台公布的模型信息为准。

第三方模型可能因维护、上游策略调整、速率限制或网络问题而暂时不可用。模型输出可能存在错误、遗漏、偏差或过时信息，您应结合具体用途自行核验后再行使用。

学习与课程场景应遵守所在学校、课程或研究项目的学术诚信与 AI 使用要求；在发布代码、报告或其他成果前，应核查其准确性及相关权利。

## 三、账号与 API Key 安全

您应提供准确的必要账号信息，并妥善保管密码、API Key、访问令牌及其他认证凭证。请勿将可用凭证公开在代码仓库、前端页面、截图或公共日志中。

团队应按职责管理访问权限，及时撤销不再使用的凭证。发现凭证泄露或异常调用时，应尽快禁用相关 Key、更新凭证，并通过本协议列明的联系方式反馈。

账号异常及相关责任的认定，将结合实际授权情况、各方过错及适用法律处理，不将所有账号活动一概认定为您本人的操作。

## 四、用户内容与使用边界

您应确保有权提交和处理提示词、文件、图像、音频及其他内容；涉及他人个人信息或保密材料时，应已取得必要授权。

您依法享有的内容权利不因使用本服务而转移。平台处理您提交内容的范围，限于提供服务所必需的请求转发、任务处理及隐私政策中已说明的其他目的。

不得利用本服务实施违法活动、侵权、诈骗、恶意攻击、未经授权的数据获取，或绕过计费、限流与安全控制。

未经平台另行同意，不得将本服务整体转售，或作为独立服务提供给第三方。平台保留根据服务定位调整上述使用边界的权利；调整将通过公告方式告知。

## 五、价格、额度与支付

本平台当前通过管理员发放额度的方式提供使用额度，**未开放在线支付、套餐购买与自动续费功能**。您获得的额度、其使用范围与有效期以平台实际发放时展示的信息为准。

您可以在控制台查询调用消耗与额度使用情况。如后续开放收费功能，平台将在开放前公布价格、计量方式、模型倍率、额度有效期、套餐权益及适用费用，并更新本协议版本。

**关于退款的特别说明：** 本平台当前未开放在线支付功能，不存在通过平台完成的付款，因此暂无适用的退款情形。本协议保留本条款，是为后续开放付费功能时提供依据。

如后续开放付费功能，退款条件、申请渠道、处理时限及服务中断补偿规则将在功能开放前随本协议更新一并公布；在此之前，平台不会就未开放的付费功能作出退款承诺。

适用法律规定的不可排除权利，不因平台内部规则而被取消。

平台发现可信的安全风险、滥用或违规行为时，可根据风险程度采取警告、限速、暂停部分功能或终止服务等必要措施，并在适当情况下说明原因、提供申诉途径。

您可随时停止使用本服务。涉及账号注销、数据删除及剩余额度处理的，按平台实际提供的流程办理；平台不会将冻结额度或拒绝处理作为所有争议的统一处理方式。

个人信息的收集、使用、共享、存储和权利请求，由配套的 [OpenBridger 隐私政策](./privacy-policy.zh-CN.md) 说明。您应避免提交与任务无关的个人信息、生产环境密钥或保密材料。
