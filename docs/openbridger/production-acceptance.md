# OpenBridger 生产验收用例

最后更新：2026-09-16

适用范围：本地、预发布、正式生产
目标：让非开发人员按照页面路径操作，并依据明确结果独立判断是否通过。

> 直接在本文件填写实际结果。证据中不得包含密码、完整 API Key、验证码、Session、支付卡资料或商户密钥。

## 0. 实际验收主线：从这里开始逐步测试

这一节是实际操作脚本。先只执行这一节，后面的章节用于发现问题后继续深挖。

### 0.1 记录方式

每完成一步，把行首的 `[ ]` 改成以下一种状态：

- `[x]`：通过，实际结果与“正确结果”一致。
- `[失败]`：结果不一致，停止当前阶段并记录问题。
- `[阻断]`：缺少上游 Key、邮箱、支付配置等条件，暂时无法执行。
- `[不适用]`：本次上线明确不提供该功能。

截图只保留页面和错误信息，必须遮挡密码、完整 API Key、验证码、Cookie 和上游密钥。

## 1. 判定与上线门槛

- **通过**：每一步都符合“正确结果”，证据完整。

- **阻断**：功能未完成、配置缺失或外部服务不可用，因而无法执行。阻断不等于通过。
- **不适用**：本次上线明确关闭该功能，且用户无法进入相关入口。

以下任一情况存在时，不得公开收费上线：

1. 任一适用 P0 用例失败、阻断或未执行。
2. 数据库没有完成一次成功的备份恢复演练。
3. 支付回调可重复入账、无法验签，或订单金额与到账额度不一致。
4. 调用出现负数、重复或无法解释的计费。
5. 主备渠道切换造成重复结算。
6. 生产未启用 HTTPS，或认证 Cookie 缺少必要安全属性。
7. 公开注册已开启，但邮箱验证或反自动化保护未生效。
8. 协议仍有“待确认”“待公布”、参考站名称或错误服务商信息。

### BILL-003 定价方案与人工审核（P0）

**UI 路径**：A0 登录 → 系统设置 → 模型与定价 → 价格控制；直接地址 `/system-settings/models/pricing-control`。

| 步骤 | 操作 | 正确结果 |
| --- | --- | --- |
| 1 | 查看上游报价状态 | 有来源、模型映射、币种、标准化价格、采集时间和过期状态。 |
| 2 | 设置主备渠道、备用占比、运营成本、目标毛利 | 非法输入被明确拒绝。 |
| 3 | 生成方案 | 有当前价、建议价、变化率、预期/最坏毛利和依据。 |
| 4 | 按下方公式复算 | 与页面在显示精度内一致。 |
| 5 | A1 尝试访问 | 无权限，不能生成、批准或发布。 |
| 6 | A0 批准并发布 | 有二次确认；发布人、时间和前后值可追溯。 |
| 7 | 发起新调用 | 新调用使用新价格；历史日志不被改写。 |

```text
加权上游成本 = 主渠道成本 × (1 - 备用占比) + 备用渠道成本 × 备用占比
含运营成本 = 加权上游成本 × (1 + 运营成本率)
目标售价 = 含运营成本 ÷ (1 - 目标毛利率)
实际毛利率 = 1 - 含运营成本 ÷ 实际售价
```

若触发最低售价、涨跌保护、压力成本或舍入，页面必须显示触发的规则。
