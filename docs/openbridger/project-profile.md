# OpenBridger 项目档案

最后更新：2026-10-10（上次 2026-09-20。本次按当日生产实测与 git 记录全面刷新：生产已上线运行三周，§3/§6/§7/§8/§9 的「待准备/待确认」状态均已过期）

## 1. 产品定位

OpenBridger 是面向大学生、开发者和团队的 AI API 网关，通过统一的 OpenAI 兼容接口连接多种模型，提供 API Key、余额与额度、调用日志、模型定价、主备渠道和管理控制台。

公开服务仅面向非中国大陆地区用户。公开页面不陈述运营所在地。正式服务范围、运营主体和适用规则以最终发布的用户协议与隐私政策为准。

## 2. 目标用户

| 用户 | 主要需求 | 首发能力 |
| --- | --- | --- |
| 大学生 | 学习实践、课程项目、低门槛接入 | 实用教程、游乐场、API Key、透明用量 |
| 开发者 | SDK、Agent 工具和应用集成 | OpenAI 兼容接口、主流模型、日志与稳定路由 |
| 小型团队 | 共享接入和成本管理 | 分组、额度、模型策略和管理控制台 |
