# OpenBridger 项目档案

最后更新：2026-09-09

## 1. 产品定位

OpenBridger 是面向大学生、开发者和团队的 AI API 网关，通过统一的 OpenAI 兼容接口连接多种模型，提供 API Key、余额与额度、调用日志、模型定价、主备渠道和管理控制台。

公开服务仅面向非中国大陆地区用户。公开页面不陈述运营所在地。正式服务范围、运营主体和适用规则以最终发布的用户协议与隐私政策为准。

## 2. 目标用户

| 用户 | 主要需求 | 首发能力 |
| --- | --- | --- |
| 大学生 | 学习实践、课程项目、低门槛接入 | 实用教程、游乐场、API Key、透明用量 |
| 开发者 | SDK、Agent 工具和应用集成 | OpenAI 兼容接口、主流模型、日志与稳定路由 |
| 小型团队 | 共享接入和成本管理 | 分组、额度、模型策略和管理控制台 |

## 3. 系统组成

| 模块 | 技术/位置 | 当前状态 |
| --- | --- | --- |
| API 网关与控制面 | Go、Gin、GORM，仓库根目录 | 已具备基础能力 |
| Web 主站与控制台 | React、TypeScript、Rsbuild，`web/` | 品牌适配和核心页面已完成 |
| 文档站 | 独立静态站，`docs-site/` | 中英文构建完成，待部署 |
| 动态定价控制 | `model/`、`service/`、`controller/` 与管理端 | 计算、审核、发布已完成；自动采集适配器待实施 |
| 主数据库 | SQLite/MySQL/PostgreSQL | 三种数据库兼容性已验证；生产数据库待选定 |
| 缓存与限流 | Redis/内存 | 能力已存在；生产 Redis 待配置 |
| 支付 | Waffo 与原有支付能力 | 代码存在；生产渠道、规则和真实验收待确认 |
| 邮件与验证 | SMTP、邮箱验证、密码恢复 | 能力存在；生产 SMTP 待配置和验收 |
