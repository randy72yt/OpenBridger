## 附录 1：试运行每日巡检清单（G3）

每天一次，记录到 `docs/openbridger/trial-daily-log.md`（首次巡检时创建）：

| 项 | 检查方法 | 异常阈值 |
|---|---|---|
| 上游成功率 | 后台用量/日志页，或 `SELECT` 近 24h logs 的 5xx 占比 | >2% |
| 上游余额 | dddai `GET /v1/dashboard/billing/usage` 日增量 | 余额不足 3 天量 |
| 毛利 | 定价管理页比对售价 vs 成本 | 任一模型毛利为负 |
| 错误率 | `/api/log` 错误类型分布（429/5xx/超时） | 单日突增 |
| 定时定价同步 | 同步任务最近执行时间、报价新鲜度（2h 有效期） | 超过 2h 未同步 |
| 容器健康 | `docker ps` 三个容器 healthy；磁盘 `df -h` | 磁盘 >80% |
| 备份 | 当日备份文件已生成且大小正常 | 缺备份 |
| 用户反馈 | 受邀用户群/邮件 | 任何 P0 投诉 |

试运行期间：所有价格变更人工审核后才发布；不新增公开注册。

## 附录 2：试用额度发放流程（G2 验收口径）

1. 管理员在后台为受邀账号发放固定试用额度（数值由用户拍板，建议每个账号等价 $5–$10）；
2. 设置单用户上限（防止试用额度累加滥用）；
3. 验收点：发放后用户 `quota` 正确增加、调用按定价扣费、额度耗尽返回额度不足而非 500、管理员可撤销/调整；
4. 验收通过后删除测试令牌 `sk-31a7...`（agent-verify，unlimited_quota=1）；
5. 记录在验收执行总表 BILL-005 行。
