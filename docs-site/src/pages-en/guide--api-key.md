# Create and manage API keys

An API key authorizes a tool or application to call OpenBridger. Use separate keys for different tools, projects, and environments.

<div class="steps"><div class="step"><strong>Open API Keys</strong><p>Sign in and open the API Keys page.</p></div><div class="step"><strong>Create a key</strong><p>Give it a recognizable name.</p></div><div class="step"><strong>Limit its scope</strong><p>Configure available groups, models, credit, or expiry when offered.</p></div><div class="step"><strong>Copy and verify</strong><p>Store it securely, then send a short test request.</p></div></div>

<div class="callout warning"><strong>Keep keys secret</strong><p>Never put a live key in browser code, a public repository, screenshots, or client logs. OpenBridger support will never ask for your password or a complete usable key.</p></div>
