Practices that matter while you call the API:

- Do not put passwords, full API keys, payment credentials, or unrelated personal data in prompts, tickets, screenshots, or public repositories.
- A request id and the first 8 characters of a key are enough for a support email.
- Both the terms and the privacy policy say the service is only for users outside mainland China. The latest page on the main site wins.

If the main site policy changes, [{{CONSOLE_URL}}/privacy-policy]({{CONSOLE_URL}}/privacy-policy) is the version to follow.
