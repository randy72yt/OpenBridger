# Use OpenBridger with Open WebUI

Adding a global connection normally requires Open WebUI administrator access.

<div class="steps"><div class="step"><strong>Open Connections</strong><p>Find OpenAI API connections in Admin Panel or Settings.</p></div><div class="step"><strong>Add OpenBridger</strong><p>Use <code>{{API_BASE_URL}}</code> and a dedicated key.</p></div><div class="step"><strong>Refresh models</strong><p>Add or restrict model IDs manually if discovery fails.</p></div><div class="step"><strong>Check logs</strong><p>Send a short message and confirm the request.</p></div></div>

<div class="callout warning"><strong>Shared access</strong><p>An administrator connection may be shared by many users. Apply appropriate model, credit, and access limits.</p></div>
