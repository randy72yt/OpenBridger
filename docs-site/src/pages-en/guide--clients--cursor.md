# Use OpenBridger with Cursor

If your Cursor version supports a custom OpenAI-compatible provider, enter the OpenBridger Base URL, API key, and exact model ID.

<div class="steps"><div class="step"><strong>Open model settings</strong><p>Look for Models, API Keys, or a custom provider.</p></div><div class="step"><strong>Add a compatible service</strong><p>Choose OpenAI Compatible or an OpenAI entry that allows a custom Base URL.</p></div><div class="step"><strong>Enter the model</strong><p>Use <code>{{API_BASE_URL}}</code> and copy the exact model ID.</p></div><div class="step"><strong>Send a short request</strong><p>Test in Chat or Agent and confirm it in Usage Logs.</p></div></div>

Cursor menus and custom-key features may vary by version or plan. Tab Completion can continue to use Cursor's own service.
