# Reasoning & Thinking Fields

Frontier models across GPT-6.2, Claude 5.5, Gemini 4, DeepSeek Reasoner, Qwen4, and Grok 4.7 support step-by-step chain-of-thought reasoning. Use this reference when tuning reasoning depth or parsing thinking tokens in your own code.

## 1. Controlling reasoning depth (request parameters)

| Wire protocol | Request field | Typical values / notes |
| --- | --- | --- |
| **OpenAI Chat** (`/v1/chat/completions`) | `"reasoning_effort": "medium"` | `"low"`, `"medium"`, `"high"` (reasoning models) |
| **OpenAI Responses** (`/v1/responses`) | `"reasoning": {"effort": "high"}` | `"low"`, `"medium"`, `"high"` (`model_reasoning_effort` in Codex `config.toml`) |
| **Anthropic Messages** (`/v1/messages`) | `"thinking": {"type": "enabled", "budget_tokens": 4096}` | `budget_tokens` must be smaller than `max_tokens` |
| **Gemini Native** (`/v1beta/models/...`) | `"generationConfig": {"thinkingConfig": {"includeThoughts": true}}` | Controls thought summary emission and thinking budget |

## 2. Where reasoning text appears in responses

Depending on the endpoint and upstream model family, reasoning output appears in one of three structures:

### A. OpenAI-compatible `reasoning_content`

On `/v1/chat/completions` (e.g. DeepSeek Reasoner and normalized reasoning adapters), thoughts are separated from the final answer:

- **Non-streaming**: `choices[0].message.reasoning_content` + `choices[0].message.content`
- **Streaming SSE**: `choices[0].delta.reasoning_content` chunks arrive first, followed by `choices[0].delta.content`

```json
{
  "choices": [
    {
      "delta": {
        "reasoning_content": "First check boundary cases n = 0 and n = 1...",
        "content": ""
      }
    }
  ]
}
```

### B. Anthropic native `thinking` content blocks

On `/v1/messages` with `thinking` enabled, `content` contains typed blocks:

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "Grouping terms of the harmonic series...",
      "signature": "..."
    },
    {
      "type": "text",
      "text": "Here is the proof: ..."
    }
  ]
}
```

### C. Inline `<think>...</think>` tags

Some open-weight model routes prepend `<think>...</think>` directly inside `content`. Desktop clients such as Cherry Studio, Chatbox, and LobeChat automatically detect and fold all three formats.

<div class="callout warning"><strong>Billing note</strong><p>Reasoning tokens generated by the model require upstream compute and are billed as output/completion tokens (<code>completion_tokens</code> / <code>output_tokens</code>). For straightforward translation or formatting tasks, use a non-reasoning model or set <code>reasoning_effort</code> to <code>low</code> for faster responses and lower cost.</p></div>
