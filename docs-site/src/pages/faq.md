# 常见问题

## Base URL 应该填什么？

OpenAI 兼容客户端通常填写 `{{API_BASE_URL}}`。只有配置项明确要求完整 Endpoint 时，才追加 `/chat/completions`。

## 为什么模型列表为空，但 Key 没报错？

部分客户端不会读取兼容接口的模型列表，或会过滤不认识的模型。请从控制台复制完整模型 ID 并手动添加。

## 怎样确认请求经过 OpenBridger？

为客户端创建一个独立 API Key，发一条短消息，然后在使用日志中按时间、模型和 Key 核对。只看客户端显示的模型名称并不可靠。

## 接入后需要退出工具原来的账号吗？

通常不需要。工具账号负责同步、订阅或编辑器功能，OpenBridger API Key 负责自定义模型请求。恢复官方模型时，切回内置 Provider 并清除相应环境变量。

## 为什么客户端请求失败？

依次检查 Base URL、API Key、账户余额、模型 ID 和当前分组权限。仍失败时参阅故障排查。

## 支持哪些客户端？

支持自定义 Base URL、API Key 和模型 ID 的工具通常都可以尝试接入。Codex、Claude Code、CC Switch 和常见 OpenAI SDK 有单独教程；具体能力取决于协议与模型。

## 钱包额度和套餐额度哪个先扣？

扣费顺序以控制台显示的账户配置和套餐规则为准。核对具体请求时，请查看使用日志中的账户分组、模型和消耗来源。

## 支持哪些充值方式？

以钱包和结账页面实时展示为准。可用方式可能因地区、币种、设备和浏览器不同；页面没有展示的方式不代表已经支持。

## 怎样恢复工具原来的官方模型？

切回内置 Provider，停用自定义 Base URL，并清除对应环境变量。CLI 和桌面客户端通常还需要重新启动。
