# 订阅套餐

除按量充值钱包外，你也可以在 [订阅页]({{CONSOLE_URL}}/subscriptions) 或 [钱包]({{CONSOLE_URL}}/wallet) 购买周期套餐。**所有套餐到期均不会自动续费扣款**，用完或到期后自行决定是否再次购买。

## 购买流程

<div class="steps">
  <div class="step"><strong>第 1 步：挑选套餐</strong><p>打开 <a href="{{CONSOLE_URL}}/subscriptions">订阅页</a>，查看卡片上的有效期、额度上限、重置周期与适用分组，点击 <strong>「立即订阅」</strong>。</p></div>
  <div class="step"><strong>第 2 步：核对确认框并付款</strong><p>核对弹窗中的应付金额（¥），选择支付宝、微信支付或「使用余额支付」（如该套餐支持且钱包余额充足）。</p></div>
  <div class="step"><strong>第 3 步：生效使用</strong><p>付款完成后立即生效，无需更换原有的 API Key。</p></div>
</div>

## 套餐与钱包同时有钱时怎么扣？

在 [钱包]({{CONSOLE_URL}}/wallet) 页面可随时切换扣费偏好（默认 **优先订阅**）：

| 扣费偏好 | 实际扣费逻辑 |
| --- | --- |
| **优先订阅（默认）** | 先扣套餐额度；若套餐当日/当期额度用完且该套餐允许回退，自动改扣钱包余额。 |
| **优先钱包** | 先扣钱包余额，钱包不足时再扣套餐额度。 |
| **仅用订阅** | 只扣套餐额度，用尽直接返回 `403` 提示订阅额度不足，绝不动用钱包余额。 |
| **仅用钱包** | 只扣钱包余额。 |
