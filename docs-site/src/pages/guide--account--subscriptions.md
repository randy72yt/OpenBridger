# 订阅套餐

主站用户协议 v1.1 写明：**套餐购买和自动续费暂未开放。** 钱包或 [订阅页]({{CONSOLE_URL}}/subscriptions) 上没有可购买套餐时，不存在套餐商品，也不要按任何外部价目表付款。

网关代码里已经有订阅额度、套餐记录和扣费偏好。这些能力只有在运营实际上架、并且协议同步更新之后，才对购买者生效。本文不列出套餐名称或价格。

## 扣费偏好（钱包里可见时）

没有订阅额度时，调用扣的是钱包。一旦账号上有可用订阅，默认偏好是「优先订阅」。

| 偏好 | 含义 |
| --- | --- |
| 优先订阅（默认） | 没有有效订阅时扣钱包。有有效订阅时先扣订阅；只有该订阅允许钱包回退时，订阅额度不足才会再扣钱包，否则返回订阅额度不足。 |
| 优先钱包 | 先扣钱包。钱包额度不足时再试订阅。 |
| 仅用订阅 | 只使用订阅额度。不够则 `403`，文案含「订阅额度不足或未配置订阅」。 |
| 仅用钱包 | 只使用钱包。 |

在钱包里能切换时，以切换后的选项为准。切换只影响之后的请求。

## 如果以后开放购买

以购买确认页和届时的协议为准，至少核对：

- 价格、币种、有效期、包含额度
- 适用的模型和分组
- 用完以后是否继续扣钱包
- 是否自动续费，以及在哪里取消
- 到期后未用额度怎么处理

处理中的订单不要重复支付。购买不成功时，到使用日志看是额度问题还是模型不在套餐范围内。
