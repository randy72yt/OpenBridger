# 订阅套餐

OpenBridger 的套餐名称、价格、额度、有效期、并发和续费规则以控制台实际展示为准。尚未展示的套餐不构成销售承诺。

套餐通常提供一段有效期内的独立额度或使用权益。它和钱包余额可能采用不同的有效期、适用模型及扣费规则，购买前需要逐项核对。

## 选择套餐时重点确认

- 支持的模型、协议和账户分组。
- 套餐额度、有效期与用完后的处理方式。
- 并发、速率或其他使用限制。
- 是否自动续费，以及取消和退款规则。
- 套餐额度与钱包余额的扣费顺序。
- 额度是否可以结转、共享、转让或叠加。
- 套餐到期后未使用额度的处理方式。

## 购买、续费与取消

- 在确认页再次核对套餐、应付金额、币种、有效期和权益开始时间。
- 只有页面明确标注“自动续费”并展示续费规则时，才视为自动续费套餐。
- 自动续费套餐应通过控制台提供的入口管理或取消；取消通常不会等同于立即删除当期权益，具体以页面规则为准。
- 购买后在钱包、套餐或订单页面核对状态。处理中不要重复下单。

## 套餐无法使用

先确认套餐仍在有效期内、剩余额度充足、目标模型属于套餐范围，且客户端使用了正确账户和分组。然后到使用日志核对实际模型和错误码。
