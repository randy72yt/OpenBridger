# 订阅套餐

套餐可以购买。入口在 [钱包]({{CONSOLE_URL}}/wallet) 和 [订阅页]({{CONSOLE_URL}}/subscriptions)。每张卡片上的名称、价格、有效期和额度就是这次购买的内容。本文不列出价格。

## 购买

<div class="steps"><div class="step"><strong>打开套餐列表</strong><p>钱包页或订阅页。只购买页面上出现的套餐。</p></div><div class="step"><strong>核对确认框</strong><p>点「立即订阅」后，确认框列出套餐名称、有效期、套餐额度、应付金额。有重置周期或升级分组时也会写在这里。</p></div><div class="step"><strong>选择付款方式</strong><p>在线支付打开时，可以用钱包里已启用的支付宝或微信。套餐允许余额支付时，确认框里有「使用余额支付」。余额不够或该套餐不允许余额支付时，这个按钮不可用。</p></div><div class="step"><strong>等结果</strong><p>支付处理中不要重复下单。成功后钱包或订阅页会显示已购套餐。同一套餐若写了每人购买次数上限，达到上限后不能再买。</p></div></div>

应付金额是确认框里的数字。人民币标价的套餐显示 ¥。不要按别的页面或聊天里的价目表付款。

## 扣费偏好

没有有效订阅时，调用扣钱包。买了套餐之后，默认偏好是「优先订阅」。

| 偏好 | 含义 |
| --- | --- |
| 优先订阅（默认） | 没有有效订阅时扣钱包。有有效订阅时先扣订阅；只有该订阅允许钱包回退时，订阅额度不足才会再扣钱包，否则返回订阅额度不足。 |
| 优先钱包 | 先扣钱包。钱包额度不足时再试订阅。 |
| 仅用订阅 | 只使用订阅额度。不够则 `403`，文案含「订阅额度不足或未配置订阅」。 |
| 仅用钱包 | 只使用钱包。 |

钱包里能切换时，切换只影响之后的请求。

## 有效期、额度和重置

确认框里的有效期是这一期的长度，例如若干月或若干天。到期后的分组如果套餐写了升级或降级，以套餐说明为准。

重置周期如果不是「不重置」，表示套餐额度按那个周期恢复。这不是再扣一次款。确认框没有「到期自动扣款」这一项。代码里也没有到期后再向支付宝或微信收一笔的开关。

套餐额度用尽时的行为由扣费偏好和该套餐是否允许回退到钱包决定。见上表。
