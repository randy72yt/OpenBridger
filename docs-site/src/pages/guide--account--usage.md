# 查看用量与日志

使用日志可以确认请求是否经过 OpenBridger、使用了哪个模型、消耗多少额度，以及失败时返回了什么状态。

## 推荐做法

- 为 Codex、Claude Code、测试脚本和生产项目分别创建 API Key。
- 使用时间范围和 Key 名称定位请求，避免只按模型筛选。
- 遇到错误时记录请求 ID、时间、模型和状态码；不要发送完整 API Key。
- 消耗异常时检查客户端是否重复发送历史消息，或启用了 Agent 工具调用。

<div class="callout"><strong>任务日志</strong><p>绘图、视频等异步任务可能出现在任务日志中，而普通对话请求通常位于使用日志。具体入口以控制台显示为准。</p></div>
