# 查看用量与日志

使用日志用来回答四件事：请求有没有打到 OpenBridger、用的哪个模型、扣了多少、失败时是什么状态。

地址：[{{CONSOLE_URL}}/usage-logs]({{CONSOLE_URL}}/usage-logs)。

## 日志里能对上的字段

- 时间
- 密钥名称
- 模型 ID
- 消耗额度
- 请求 ID（响应头 `X-Oneapi-Request-Id`，错误正文末尾也有 `(request id: …)`）

绘图等异步任务看任务或绘图日志（`/usage-logs/task`、`/usage-logs/drawing`），不要只在对话日志里找。

## 建议

- 每个客户端一把密钥，筛选时用密钥而不是只看模型名。
- 客户端显示的模型名可能是它自己的别名。以日志里的模型 ID 为准。
- 报障时提供请求 ID、时间（含时区）、模型 ID 和状态码。密钥只给前 8 位，例如 `sk-abcd`。
- 消耗突然变高时，看是不是把全部历史又发了一遍，或 Agent 连续调用了工具。

## 和预扣的关系

日志在结算之后写入。预扣阶段就失败的请求（例如额度不足）可能没有一条成功消耗记录，但错误响应里仍有请求 ID。把那次 `curl` 或客户端的错误正文留住。
