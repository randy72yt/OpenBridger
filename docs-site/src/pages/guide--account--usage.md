# 查看用量与日志

打开控制台 [使用日志]({{CONSOLE_URL}}/usage-logs)，即可逐笔核对：请求是否打到了 OpenBridger、实际跑的哪个模型、用了多少 Token、扣了多少钱。

## 日志怎么看

| 列名 | 怎么用 |
| --- | --- |
| **时间 & 密钥名** | 给每个软件单独建一把密钥（如 `codex`、`cherry`），按密钥名筛选一眼就能对账。 |
| **模型 ID** | 显示本次实际路由的模型标识（部分客户端界面显示的是别名，以日志里的模型 ID 为准）。 |
| **提示 / 补全 Token** | 分别对应本次发送的输入（含历史上下文）与模型生成的输出（含思考过程）。 |
| **花费（¥）** | 结算后的真实扣费金额。 |
| **请求 ID** | 对应响应头 `X-Oneapi-Request-Id`。遇到异常联系支持时复制此 ID 即可快速定位。 |

- **图像与视频任务**：异步生图、视频任务记录在「任务日志 / 绘图日志」标签页下，不在普通对话列表里。
- **没有产生记录的情况**：如果在发请求瞬间就报 `404`（地址写错未进网关）或 `403 用户额度不足`（预扣未通过），对话消耗列表不会新增扣费记录。
