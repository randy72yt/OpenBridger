# 联系与故障申报

- **官方支持邮箱**：[support@openbridger.com](mailto:support@openbridger.com)
- **实时服务状态页**：<https://stats.uptimerobot.com/aHV66DcfpB>（遇到大面积超时可先看一眼状态页）

## 发邮件时请提供这 4 项信息（处理最快）

1. **你的注册邮箱或用户名**
2. **报错状态码与 `request id`**（报错弹窗或 [使用日志]({{CONSOLE_URL}}/usage-logs) 里的请求 ID）
3. **使用的客户端名称与模型 ID**（例如 `Codex 桌面版 + gpt-6.2-astra`）
4. **密钥前 8 位**（如 `sk-abcd12...`，用于定位密钥配置）

> **充值未到账 / 退款申请**：附上支付时间、金额与微信/支付宝账单号即可（退款规则见 [充值与兑换](/guide/account/redeem/)）。如果是紧急服务中断，邮件标题可加 `[URGENT]`。

<div class="callout warning"><strong>切勿发送敏感凭证</strong><p>任何情况下都<strong>不要</strong>在邮件或截图里透露你的账号密码、短信验证码、完整 <code>sk-...</code> 密钥或完整兑换码。官方人员绝不会索要这些信息。</p></div>

## 响应时间

一般咨询与账单问题通常在 **1 个工作日内** 回复（节假日与深夜顺延），服务可用性故障优先处理。
