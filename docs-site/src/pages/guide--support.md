# 联系与故障申报

OpenBridger 目前处于试运行阶段，支持渠道和响应时效说明如下。

## 联系方式

| 场景 | 渠道 | 说明 |
| --- | --- | --- |
| 使用问题、账单疑问、额度申请 | [support@openbridger.com](mailto:support@openbridger.com) | 邮件是唯一官方支持渠道 |
| 服务是否正常 | 服务状态页 | 先看状态页，再决定是否报障 |
| 紧急故障 | 邮件标题加 `[URGENT]` | 会优先处理 |

服务状态页：<https://stats.uptimerobot.com/aHV66DcfpB>

## 响应时效（试运行阶段）

| 类型 | 首次响应 |
| --- | --- |
| 一般咨询 | 1 个工作日内 |
| 账单与额度 | 1 个工作日内 |
| 服务中断 | 先查状态页；已确认的故障会优先处理并尽快通报 |

试运行期间为人工支持，非 7×24 值守；深夜与节假日的响应会顺延。

## 报障前请准备好这些信息

缺少这些信息会来回追问，明显拖慢处理速度：

1. 账号（注册用户名或邮箱）
2. 出问题的时间（含时区）与频率（偶发 / 必现）
3. 使用的模型 ID 和客户端（如 Codex、Claude Code、SDK）
4. 完整错误信息，或控制台「用量与日志」里对应请求的截图
5. 已经做过的排查（换模型、换 Key、重启客户端等）

## 额度与充值

- 新用户注册后自动获得一笔试用额度
- 额外额度通过兑换码发放，在控制台「充值与支付」中输入兑换码即可到账
- 需要额度时发邮件到 [support@openbridger.com](mailto:support@openbridger.com)，说明用途与大致用量

## 安全与隐私

- 邮件中**不要**发送完整 API Key、密码、二次验证码
- 需要协助排查时，提供 Key 的前 8 位即可，我们会按账号定位
- 官方不会通过邮件、私聊索要你的密码或完整密钥
