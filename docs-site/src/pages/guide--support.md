# 联系与故障申报

支持邮箱：[support@openbridger.com](mailto:support@openbridger.com)。这是公开的支持渠道。

服务状态页：<https://stats.uptimerobot.com/aHV66DcfpB>。先看状态页，再决定要不要报障。

## 发信前准备

1. 账号的用户名或邮箱。
2. 发生时间（写上时区）和是偶发还是必现。
3. 模型 ID、客户端名称。
4. HTTP 状态、错误正文，以及 `X-Oneapi-Request-Id`。也可以附上使用日志里该条记录的截图，截图里不要包含完整密钥。
5. 已经试过的步骤：换模型、换密钥、curl 是否成功。

邮件标题如果是服务已经不可用，可以加上 `[URGENT]`。

## 不要发这些

- 密码、二次验证码、支付密码、短信验证码
- 完整 API Key、完整兑换码

密钥最多给前 8 位。官方不会在邮件或私聊里向你要密码或完整密钥。

## 账单

充值未到账、退款和扣费异议用同一邮箱。附上金额、时间和订单号。退款范围以 [用户协议](/legal/terms/) 为准：已消耗额度不退，未消耗的充值余额可申请按原路退回。

加额度的正常方式是钱包里的在线充值或兑换码，不是发邮件索取额度。见 [充值与兑换](/guide/account/redeem/)。

## 响应

试运行期间是人工处理，不是 7×24 值守。一般咨询、账单问题按 1 个工作日内首次回复安排；已经确认的服务中断会优先处理。深夜和节假日顺延。

这个时效是当前对外说明，不是接口里的保证。若以后调整，以本页更新后的文字为准。
