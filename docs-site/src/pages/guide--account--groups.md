# 分组与线路说明

分组用于决定账户可使用的模型、线路和计费规则。用户无需理解内部渠道配置，只需按照控制台展示的可用模型使用。

## 使用建议

- 客户端模型列表必须来自当前分组可用范围。
- 同名模型在不同线路上的协议、速率和稳定性可能不同。
- 出现 403 或模型不可用时，先检查分组权限，不要反复更换 API Key。
- 团队环境应统一记录各项目使用的分组和模型，便于排查。
