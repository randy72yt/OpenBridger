# 分组与线路

创建或编辑 [API 密钥]({{CONSOLE_URL}}/keys) 时可以选择 **分组（Group）**。不同分组对应不同的模型范围、上游线路与计费倍率，具体以 [模型广场]({{CONSOLE_URL}}/pricing) 切换分组后显示的列表和价格为准。

## 创建密钥时分组怎么选？

| 选项 | 适用场景 |
| --- | --- |
| **保持默认 / 留空** | 跟随你账户当前的默认分组，最省心。 |
| **`auto`（自动分组）** | 按你设定的分组优先级依次匹配；开启「跨分组重试」后，当前分组偶发繁忙会自动切到下一组。 |
| **指定某个分组** | 当你想把某把密钥锁定在特定专线（例如专门给 Codex 或 Claude Code 用的分组）时选择。 |

## 常见提示

- **报 `503 分组 xxx 下模型 yyy 无可用渠道`**：说明这把密钥选的分组里没有开放该模型（或不支持当前协议）。去 [模型广场]({{CONSOLE_URL}}/pricing) 看该模型支持哪些分组，回 [API 密钥]({{CONSOLE_URL}}/keys) 修改密钥分组或改为 `auto` 即可。
- **报 `403 无权访问某分组`**：该分组不在你当前账户等级或套餐可用范围内，改回默认分组即可。
