# 额度与计费

模型调用可能根据输入、输出、缓存、工具调用、多模态单位和账户分组计算消耗。模型广场与请求日志是核对计费的主要入口。

## 查看一次请求的消耗

<div class="steps"><div class="step"><strong>记录请求时间</strong><p>发送测试请求前记下时间，并为测试工具使用独立 API Key。</p></div><div class="step"><strong>打开使用日志</strong><p>按时间、Key 或模型筛选请求。</p></div><div class="step"><strong>核对模型与用量</strong><p>查看输入、输出、缓存及其他计量单位。</p></div><div class="step"><strong>检查分组</strong><p>确认请求使用的账户分组和模型定价与预期一致。</p></div></div>

<div class="callout warning"><strong>以控制台为准</strong><p>支付方式、套餐、兑换码和扣费优先级只在平台实际开放并显示时生效。本文档不预先承诺尚未配置的支付或订阅能力。</p></div>
