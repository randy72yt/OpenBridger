# 充值与兑换

钱包地址是 [{{CONSOLE_URL}}/wallet]({{CONSOLE_URL}}/wallet)。增加额度有两条路：页面上打开的在线支付，或兑换码。没有出现的支付按钮就还没开通，不要通过聊天里的链接付款。

<div class="callout"><strong>截图待补</strong><p>钱包页：余额、金额档位、支付宝/微信按钮、兑换码入口、支付成功后的余额变化。由运营用当前界面替换本段。</p></div>

## 开始之前

- 登录的是你要充值的账号。
- 只使用钱包页打开的收银台。
- 准备好能支付的支付宝或微信。代码里的默认方式包含支付宝（`alipay`）和微信（`wxpay`）。页面上多出来的按钮是另行配置的，只使用钱包上实际出现的按钮。

在线支付总开关打开时，钱包才显示充值。开关关闭时，页面只保留兑换，创建订单会被拒绝。

## 在线充值

<div class="steps"><div class="step"><strong>打开钱包</strong><p>确认账号。页面标题在可充值时是「添加资金」。</p></div><div class="step"><strong>选择金额</strong><p>金额是人民币。默认最低 ¥10。快捷档位是 ¥10、¥20、¥50、¥100、¥200、¥500、¥1000、¥5000。页面若显示别的下限，以下限为准。低于下限时下单会失败，文案是「充值数量不能小于 …」。</p></div><div class="step"><strong>核对确认页</strong><p>确认页上的人民币金额就是将要从支付宝或微信扣除的金额。付完后刷新钱包，余额也按人民币显示。不要自己乘汇率。</p></div><div class="step"><strong>完成支付</strong><p>支付结束会回到 <code>/wallet?pay=success</code>。回到钱包刷新余额和充值记录。订单还在处理时不要再付一笔同样的。</p></div></div>

支付由 epay 协议接到你看到的支付宝或微信收银台。OpenBridger 客服不会向你要支付密码、短信验证码或完整卡号。

## 兑换码

<div class="steps"><div class="step"><strong>只使用官方发的码</strong><p>来源应是 OpenBridger 发给你的渠道。不要使用来路不明的码。</p></div><div class="step"><strong>在钱包兑换</strong><p>钱包里的「兑换额度」入口提交整段兑换码。</p></div><div class="step"><strong>看结果</strong><p>成功后余额和记录会增加。失败时不要把完整兑换码发给别人，也不要连续狂点。</p></div></div>

## 付了但余额没变

1. 看收银台是成功、处理中、取消还是失败。
2. 回到钱包刷新。支付通知可能比页面晚一点。
3. 不要为了「刷新余额」重复支付。
4. 仍未到账时，发邮件到 [support@openbridger.com](mailto:support@openbridger.com)，写上账号邮箱、支付时间、金额、支付方式，以及你能看到的订单号。不要附带支付密码或验证码。

## 退款

以主站 [用户协议]({{CONSOLE_URL}}/user-agreement) 为准。协议 v1.1 的约定是：

- 充值会兑换成额度。已经花掉的额度不退。
- 还没花的充值余额，可以邮件申请退款。核实后按原支付路径退回。
- 支付渠道已经收取的手续费不退。
- 申请后 7 个工作日内回复处理结果。
