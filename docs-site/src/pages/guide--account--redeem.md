# 充值与支付

OpenBridger 支持通过钱包页面提供的在线结账入口或兑换码增加账户额度。可用渠道会因地区、币种、设备和浏览器而不同，一切以结账页面当时显示的方式为准。

## 在线充值

<div class="steps"><div class="step"><strong>进入钱包</strong><p>登录控制台，打开钱包或充值页面。确认当前登录的是准备充值的账户。</p></div><div class="step"><strong>确认金额与订单</strong><p>选择页面提供的金额或套餐，仔细核对币种、支付金额、到账额度和订单信息。</p></div><div class="step"><strong>进入结账页面</strong><p>仅使用 OpenBridger 钱包页面直接打开的结账入口，不要通过聊天消息或陌生链接付款。</p></div><div class="step"><strong>选择支付方式</strong><p>使用结账页面实际显示且适合你的方式完成付款。某些数字钱包只会在兼容的设备和浏览器中出现。</p></div><div class="step"><strong>核对到账</strong><p>付款后返回钱包，刷新余额并检查交易记录。订单仍在处理时不要重复付款。</p></div></div>

## 兑换码

<div class="steps"><div class="step"><strong>获取有效兑换码</strong><p>只使用 OpenBridger 官方页面或认可渠道提供的兑换码。</p></div><div class="step"><strong>输入并确认</strong><p>在钱包的兑换区域完整输入代码，确认账户和兑换信息后提交。</p></div><div class="step"><strong>检查结果</strong><p>兑换成功后核对新增额度与记录。兑换失败时不要反复提交或向他人展示完整兑换码。</p></div></div>

## 付款后没有到账

1. 确认结账页面是否明确显示付款成功，而不是仍在处理、取消或失败。
2. 返回钱包刷新余额和交易记录，并等待支付状态完成同步。
3. 不要因为页面暂未更新而连续创建相同订单或重复付款。
4. 仍未到账时，通过主站公布的支持渠道提交订单号、付款时间、金额、币种和账户邮箱。

## 退款与争议

退款资格、退回路径、处理时间及手续费以购买时展示的规则和正式用户协议为准。发起咨询时提供订单号和问题描述即可，不要提交支付密码、验证码或完整银行卡资料。

<div class="callout warning"><strong>支付安全</strong><p>OpenBridger 客服不会索要支付密码、短信验证码、完整银行卡号、钱包密码或完整 API Key。支付渠道、退款规则与处理时间以页面和正式协议为准。</p></div>
