# 充值与兑换

所有余额充值与兑换码操作都在控制台 [钱包]({{CONSOLE_URL}}/wallet) 页面完成（请勿相信任何群聊私发的第三方收款链接）。

## 方式一：在线充值（支付宝 / 微信）

<div class="steps">
  <div class="step"><strong>第 1 步：打开钱包页</strong><p>登录控制台，进入左侧菜单 <a href="{{CONSOLE_URL}}/wallet">钱包</a>。</p></div>
  <div class="step"><strong>第 2 步：选择充值金额</strong><p>点击快捷面额（如 ¥10、¥20、¥50、¥100 等）或输入自定义金额（不低于页面提示的最低起充额）。</p></div>
  <div class="step"><strong>第 3 步：选择支付方式完成付款</strong><p>点击页面展示的 <strong>支付宝</strong> 或 <strong>微信支付</strong> 按钮，核对确认页金额后扫码支付。付完自动跳回钱包页，刷新即可看到最新人民币余额（若网络回调稍慢请等 10～30 秒刷新，切勿重复扫码付款）。</p></div>
</div>

## 方式二：使用兑换码

1. 打开 [钱包]({{CONSOLE_URL}}/wallet)，找到 **「兑换额度」** 输入框。
2. 完整粘贴官方发放的兑换码，点击兑换，余额立即到账。

## 付款后未到账或申请退款

- **未到账处理**：刷新钱包页仍未入账时，发送邮件至 [support@openbridger.com](mailto:support@openbridger.com)，附上注册邮箱、支付时间、金额与支付订单号（切勿发送支付密码或验证码）。
- **退款规则**（以主站 [用户协议](/legal/terms/) 为准）：
  - 已消耗的额度不支持退款；
  - 尚未消耗的充值余额可发邮件申请按原支付路径退回（扣除支付渠道已收取的手续费），7 个工作日内回复处理结果。
